# ML-Dataset Builder: Automotive Market

## About The Project
A Python-based desktop application designed to securely collect, validate, and store car market data. Built with the future in mind, its primary goal is to ensure data integrity and prevent "garbage data" from entering the database, creating clean datasets ready for Data Analysis and Machine Learning pipelines.

## Architecture & Technologies
The project is built entirely upon **Object-Oriented Programming (OOP)** principles and strictly follows the **MVC (Model-View-Controller)** design pattern to ensure scalability and separation of concerns.

* **Language:** Python 3
* **GUI:** Tkinter (`vista.py`)
* **Database:** SQLite3 (`conexion.py` & `modelo.py`)
* **Documentation:** Sphinx (reStructuredText)
* **Code Standard:** PEP 8 Compliant

## Business Rules & Data Validation
A dedicated validation module (`validaciones.py`) acts as a strict checkpoint before any database transaction, handling exceptions gracefully:
* **Unique Identifiers:** Regex implementation to allow only alphanumeric IDs.
* **Temporal Logic:** Prevents entry of vehicles outside valid year ranges (1930 - 2026).
* **Numeric Integrity:** Blocks negative values for metrics like mileage and USD price.
* **Mechanical Logic:** Verifies engine displacement ranges and enforces even-numbered valves using modulo operators.

## Getting Started
1. Ensure Python 3 is installed on your local machine.
2. Clone this repository.
3. Run the main application file from your terminal:
   ```bash
   python main.py
   ```

The SQLite database (autos_mercado.db) will be automatically generated in the root directory upon the first execution.
